# ПравоТека

ПравоТека — open-source сервис юридической самопомощи в Telegram и VK.
Пользователь может найти типовой правовой кейс, прочитать пошаговое решение и
получить связанный DOCX-шаблон.

Контент обоих ботов хранится централизованно. Обновление категорий, кейсов и
документов выполняется вручную через административную панель или отдельную
команду синхронизации с Яндекс.Диском.

## Возможности

- Telegram- и VK-боты с общей базой материалов;
- категории, общий список и полнотекстовый поиск по кейсам;
- контекстная навигация назад к поиску или выбранной категории;
- отправка DOCX-шаблонов;
- согласие на обработку персональных данных;
- история просмотров и обратная связь;
- закрытая web-админка;
- ручная синхронизация с Яндекс.Диском;
- миграции БД и автоматические тесты;
- запуск через Docker Compose или напрямую.

## Стек

- Python 3.11–3.13;
- FastAPI, Uvicorn и Pydantic;
- PostgreSQL, SQLAlchemy и Alembic;
- aiogram для Telegram;
- vkbottle для VK;
- httpx и aiohttp;
- Jinja2;
- uv;
- Docker Compose и Caddy.

## Быстрый старт для разработки

Понадобятся PostgreSQL и
[uv](https://docs.astral.sh/uv/getting-started/installation/).

```bash
cp .env.example .env
uv sync --locked
uv run --locked alembic upgrade head
```

Запустите процессы в трёх терминалах:

```bash
uv run --locked python -m backend
uv run --locked python -m tg_bot
uv run --locked python -m vk_bot
```

Локальные адреса:

- админка: <http://127.0.0.1:8000/admin>;
- OpenAPI: <http://127.0.0.1:8000/docs>;
- healthcheck: <http://127.0.0.1:8000/health>.

Синхронизация с Яндекс.Диском не выполняется автоматически:

```bash
uv run --locked python -m backend.sync_cases
```

## Проверка

```bash
uv run --locked python -m compileall -q backend bot_client database infrastructure tg_bot vk_bot
uv run --locked pytest -q
```

## Развёртывание

Инструкции для Docker Compose и обычного запуска на сервере находятся в
[руководстве по развёртыванию](docs/DEPLOYMENT.md).

## Безопасность

- не добавляйте `.env`, токены, пароли, дампы БД и пользовательские данные в Git;
- используйте разные API-ключи для Telegram и VK;
- публикуйте административную панель только через HTTPS;
- перед публичным запуском замените все тестовые токены и секреты;
- сообщайте об уязвимостях владельцам проекта приватно, без публикации секретов
  и персональных данных в issue.
